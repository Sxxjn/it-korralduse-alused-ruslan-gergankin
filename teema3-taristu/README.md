# Teema 3: IT taristu

## Põhimõisted

- **Server** – arvuti, mis pakub teenuseid teistele arvutitele (nt veebileht, andmebaas)
- **Võrk** – seadmed (kaablid, ruuterid, lülitid), mis võimaldavad andmeedastust
- **Andmekeskus** – füüsiline koht, kus hoitakse servereid ja võrguseadmeid
- **Pilveteenus (Cloud)** – IT-ressursid (serverid, salvestusruum), mida kasutatakse interneti kaudu
- **Koormuse jaotus (Load Balancing)** – jaotab liikluse mitme serveri vahel, et süsteem ei kuku kokku

## Mida õppisin

Taristu on nagu maja vundament – kui see on nõrk, siis kõik muu variseb kokku. Enne seda teemat arvasin, et piisab ühest suurest serverist. Nüüd tean, et modernses IT-s kasutatakse pilve, koormuse jaotust ja varundust.

## Näide

Kui kooli veebileht on ühel serveril ja see server läheb katki, siis keegi ei pääse veebilehele. Kui aga kasutada pilve (nt AWS) ja koormuse jaotust, siis isegi kui üks server langeb, teised võtavad töö üle.
