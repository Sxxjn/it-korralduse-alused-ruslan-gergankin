# Teema 2: Protsessid IT-s

## Põhimõisted

| Mõiste | Selgitus |
|--------|----------|
| Protsess | Tegevuste jada, mis muudab sisendid väljunditeks |
| Protsessi omanik | Isik, kes vastutab protsessi tulemuse eest |
| KPI (Key Performance Indicator) | Mõõdik, mis näitab protsessi efektiivsust |
| Workflow | Töövoog – sammud, mis järgnevad üksteisele |
| SLA (Service Level Agreement) | Kokkulepe teenuse kvaliteedi ja kättesaadavuse kohta |

## Mida õppisin

Protsessid aitavad teha tööd ühtlasemalt. Igal sammul peaks olema selge vastutus. Kui protsess on hästi kirjeldatud, siis uued töötajad saavad kiiresti asjast aru.

## Näide

Koolis on õppekorralduse protsess:
1. Õpetaja koostab ainekava
2. Õpilane registreerub
3. Toimuvad tunnid
4. Toimub eksam
5. Õpetaja paneb hinde

Iga samm on vajalik. Kui mõni samm puudub, tekib segadus.
